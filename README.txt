# Shoe Stock Inventory Manager

A Python program for managing a shoe store's stock, built for my
HyperionDev Software Engineering bootcamp.

It reads shoe data from `inventory.txt` and gives a menu to:
- view all shoes in a table
- add a new shoe
- restock the shoe with the lowest quantity (and save it to the file)
- search for a shoe by its code
- show the total stock value of each shoe
- find the shoe with the highest quantity to put up for sale

## How to run it
1. Install the tabulate module: `pip install tabulate`
2. Run `python inventory.py` in the same folder as `inventory.txt`
